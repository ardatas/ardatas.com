Gump was built during the TUM.ai Makeathon for a deforestation-detection case
using Sentinel satellite data and precomputed foundation-model embeddings.

The project focused on turning geospatial inputs into a machine learning
workflow that could classify deforestation signals across different continents.
The work combined PyTorch model training, prepared satellite features, and test
pipelines for repeatable experimentation.

The team also used coding agents to accelerate setup and iteration around model
training and evaluation. The final result reached a competitive top-five score
in the challenge, with accuracy reported against the event benchmark.

The main takeaway was not just model performance. It was learning how to build a
usable ML workflow under time pressure: prepare data, keep experiments
reproducible, and make the evaluation loop fast enough for meaningful iteration.
